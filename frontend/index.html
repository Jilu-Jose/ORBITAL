SECTION 06 // SYSTEM SPECIFICATIONS

End-to-end mission pipeline

01 // Ingest

Space-Track

GP elements, SATCAT and public CDMs downloaded to data/raw.

02 // Process

Spark features

Clean, join, altitude shells, shell density, pair differences.

03 // Cluster

KMeans regimes

Standardised altitude, inclination and eccentricity; k tuned by silhouette.

04 // Classify

LR / RF / GBT

Time-split training with class weights. Label: Pc > 1e-4.

05 // Serve

FastAPI + dashboard

Predictor endpoint with a deterministic rules fallback.

Screening and risk-ranking tool, not a precise collision predictor: TLE accuracy is kilometre-level and public CDM data is limited. Demo values are placeholders and must not be reported as findings.
